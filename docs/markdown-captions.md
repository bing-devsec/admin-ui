# Markdown 图注

在独立图片、Mermaid 代码块或 HTML 演示引用下方添加一行 `:caption[图 1 说明文字]`。
图注编号由作者按需填写。图注支持强调、行内代码和链接。

管理端点击“导入图片”，上传成功后会自动在图片下方插入 `:caption[在这里填写图注]` 并选中说明文字，直接输入即可。不需要图注时，删除整行 `:caption[...]`，图片会按普通图片显示。
也可以把光标放在已有图片、Mermaid 图表或 HTML 演示下方，点击工具栏的“插入图注”补充说明。工具栏不再提供在线画图入口，本地 SVG 图片仍可正常导入。

```markdown
![图片的替代文本](/images/example.svg "悬浮提示")

:caption[图 1 用户登录流程]
```

上传图片产生的原生 `<img>` 同样支持，保留作者指定的尺寸：

```markdown
<img src="/images/example.drawio.svg" alt="流程示意" width="320" />

:caption[图 2 **授权码**的流向]
```

````markdown
```mermaid
flowchart LR
    A[发起登录] --> B[确认身份]
```

:caption[图 3 登录流程]
````

图与图注可直接相邻，也可有空行；两者必须位于同一个列表项、引用或正文容器，中间不能插入其他正文。
只有明确的独立图片（包括链接包裹的图片）、Mermaid 与 HTML 演示引用支持绑定。行内图片、多图混排、普通代码示例、任意 HTML 容器不自动归组；没有对应图的标记保留为普通文字。

图注中的原生 HTML 按文字显示；`alt` 和 `title` 不自动变为图注。既有图片未添加图注时保持原有展示。

图注在 PC、平板与手机上居中显示，字号 13–14px，长内容自然换行。图注在 Mermaid 滚动区域之外；现有全屏查看器仍只显示图本身。
