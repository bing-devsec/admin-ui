# 在文章中插入 HTML 演示

打开「写文章 → 图示 → 导入 HTML 演示」，选择单个 UTF-8 编码的 `.html` 或 `.htm` 文件，大小上限为 2 MiB。上传成功后，写作区会在光标处插入一个独占一行的引用。预览或门户中的读者可以点击打开演示。

```markdown
:html-embed[0123456789abcdef0123456789abcdef]
:caption[图 1 汉诺塔的递归调用和圆盘移动]
```

示例中的编号仅用于说明格式。实际引用应使用后台上传时返回的编号。图注可按需添加，同一个编号可以用于多篇文章。修改演示内容后重新导入，再替换需要更新的引用。

## 本地测试

开发环境未配置 COS 时，Go 服务将导入的演示保存在 `meta-api/var/article-html-embed/<id>.gz`。在本地「图示 → 导入 HTML 演示」选择原文件后，后台和门户即可通过同一台本地 Go 服务读取它。仅复制 Markdown 会带上编号，文件仍需在当前环境导入一次。同一份文件内容在本地和生产会得到相同的编号，上线时可在目标环境导入原文件，继续使用已有引用。

## 可以发给 AI 的要求

> 为这段讲解生成一个可以离线使用的、自包含的 HTML 文件。将 CSS 和 JavaScript 写入文件，图片和图标用内联 SVG 或嵌入数据，所有功能在演示内部完成。布局可适应手机和桌面宽度，按钮支持键盘操作。提供清晰的初始画面、播放、暂停、重置，以及讲解需要的交互。文件使用 UTF-8，总大小控制在 2 MiB 以内。

文章用 Markdown 撰写，演示 HTML 单独导入。正文只保存引用，读者点击「打开互动演示」才下载文件。收起演示会释放运行状态，再次打开会从头开始。

演示在隔离的框架中运行内联脚本、CSS 和 SVG，图片与字体可使用 data: 地址。所有资源须打包在单个 HTML 内，远程网络请求及外链依赖不可用。框架限制访问父页面、弹出新窗口和直接下载。
